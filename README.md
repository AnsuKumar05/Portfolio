# Portfolio Website - Ansu Kumar R

## Overview
A modern, responsive, glassmorphic single-page portfolio website for **Ansu Kumar R**, Software Developer & Backend Specialist. Built to showcase technical skills, professional work experience, key projects, education, certifications, and contact information strictly aligned with his resume.

## Tech Stack & Architecture
- **HTML5 & JavaScript**: Clean semantic markup, structured JSON-LD schema, interactive UI and form handling.
- **Tailwind CSS & Bootstrap 5**: Harmonized responsive grid, layout utilities, and custom glassmorphism design system.
- **Icons**: Devicon (tech icons) & Bootstrap Icons (UI icons).
- **Responsive & Mobile-First**: Optimized for mobile phones, tablets, laptops, and ultra-wide displays.
